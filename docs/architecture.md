# Architecture

```text
Browser
  └─ Vite React SPA (home + /docs)
        └─ Cloudflare Pages (static assets + SPA _redirects)

GitHub Actions
  ├─ CI & Deployment     → quality + Pages deploy (main)
  ├─ Pulumi Cloudflare   → preview → gated pulumi up
  ├─ Refresh derived     → changelog + docs screenshots
  ├─ Lighthouse          → weekly report artifact
  └─ CodeQL              → security analysis
```

## Boundaries

- **App (`app/src/`)**: UI and in-app docs viewer (`@steerco/app`).
- **Core (`app/packages/core`)**: Pure SteerSpec domain (`@steerco/core`) - parse, validate, serialize; no React or filesystem.
- **Docs (`docs/`)**: Markdown source of truth; ADRs under `docs/ADRs/`. Product planning lives under `plan/`.
- **Infra (`infra/cloudflare`)**: Pages project and optional custom domains only (no object storage).
- **Derived outputs**: `CHANGELOG.md` and `docs/screenshots/` regenerated by `bin/sync-derived.sh`.

See [Overview](/docs) and [Workflows](/docs/workflows) for the product view of the same layout.
